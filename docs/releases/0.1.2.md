# 0.1.2

Added `resume_goal` for explicitly resuming a paused native Goal after checking
`get_goal` and passing its exact ID. The resumed goal keeps its native ID and
objective; the native reviewer still determines completion. An already active
goal is returned unchanged, and a completed goal cannot be resumed - use
`replace_goal` for a new objective instead.

Permission requests now carry the `resume` resource of the `goal` action and
display `Goal operation: resume` beside the native TUI form. Host permission
rules and confirmation buttons remain unchanged. On OpenCode 2.4.1, Plan
resumption from a reviewer-paused goal returns active state; immediate tool
readback confirms the same ID and objective. The reviewer may pause it again
after the turn. Stale-ID refusal is checked separately, and the permission
label is verified at 120 and 60 columns.

Version 0.1.1 fixed the npm-installed TUI loading defect; see the
[0.1.1 notes](0.1.1.md) and the
[installation instructions](../../README.md).
