# 0.1.1

Fixed TUI loading for packages installed under `node_modules` in OpenCode 2.3.2.
The package now ships a precompiled Solid ESM entry instead of JSX. Solid and
OpenTUI remain supplied by OpenCode, with no added runtime dependencies.

The native Goal tools, permission decisions, confirmation buttons, and operation
labels are unchanged. Package verification installs the exact archive into an
empty consumer and checks native lifecycle, Plan operations, and TUI labels
appearing and disappearing at 120 and 60 columns.

Version 0.1.0 is already on [npm](https://www.npmjs.com/package/opencode-native-goal-tools)
and has the installed-layout TUI defect. Use the [installation instructions](../../README.md)
for source, built archives, or registry installation after checking version availability.
